# Changelog

## 1.3.0 – 2026-09-29

* Support for **Minecraft 26.3** (new build node `26.3.x`, Fabric API 0.161.0+26.3).
  With 26.3, Minecraft replaced GLFW with SDL3: physical key and mouse polling, the default
  keys and the calls for swinging and dropping have been adapted accordingly.
* **Freecam compatibility**: while Freecam (xolt) is active, AUTOATTACK keeps attacking. The
  mod then aims from the player itself, because Freecam blocks the regular attack. Single
  attacks on entities only; holding, block breaking and right-click stay blocked under
  Freecam.

## 1.2.0 – 2026-09-08

* New extension point for other mods: `ScreenExtension`/`ScreenExtensions` let them hook
  their own sections into the settings screen (in the same scrollable area as the built-in
  options), `HudLineProvider`/`HudExtensions` let them show additional lines in the HUD.
  Without an installed extension, behaviour is unchanged.

## 1.1.0 – 2026-09-03

* The mod is now called **OviClicker** (previously "AutoClicker"). Renamed: the mod ID
  (`oviclicker`), the display name, the Java package, all classes, assets and translation
  keys.
* New mod icon, generated by `tools/make_icon.py`.
* **AutoEat**: when hunger drops below the configured threshold, the mod pauses clicking and
  eats. Only food without harmful consumption effects, with separate options for golden and
  enchanted golden apples, and with restocking from the inventory.
* The config file is now `config/oviclicker.json`. The old `config/autoclicker.json` is
  **not** migrated; settings start at their defaults.

## 1.0.0

* First release: modes OFF, AUTOATTACK and TIMER, freely selectable action, custom settings
  screen, HUD, rebindable keys.
* One codebase for Minecraft 1.21.11, 26.1–26.1.2 and 26.2, managed with Stonecutter.
